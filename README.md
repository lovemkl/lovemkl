# Hi, I'm @lovemkl 👋

Independent developer building free, browser-based tools. Everything I ship runs client-side — no signup walls, no uploads.

## What I'm building

- 🏈 **[RosterWorth](https://rosterworth.com)** — dynasty fantasy football trade calculator with explainable values (every number shows its formula), 1QB & Superflex
- 💾 **[DiskLens](https://disklens.org)** — disk space analyzer for Mac that runs entirely in your browser: treemap, largest files, duplicates, AI cleanup plan
- 🖼️ **[WatermarkPhoto](https://watermarkphoto.xyz)** — add text/logo watermarks and remove watermarks from photos, fully client-side
- 📊 **[GPTChart](https://gptchart.site)** — paste text or CSV, get a clean chart instantly

## Open datasets & lists
